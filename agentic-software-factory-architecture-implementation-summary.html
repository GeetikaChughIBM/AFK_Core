State Model

Worker States

REGISTERED → PROVISIONING → BOOTSTRAPPING → READY ←──────────────┐ → ASSIGNED │ → EXECUTING │ → AVAILABLE (→ READY) ──┘ → OFFLINE → FAILED

Task States

QUEUED → ASSIGNED → PROVISIONING → EXECUTING → VALIDATING → AWAITING_HUMAN_REVIEW → APPROVED → MERGED → REJECTED → FAILED → (retry) → QUEUED → FAILED (terminal)

DB2 Bootstrap Sequence

Orchestrator SSH → Worker 1. Run bootstrap/common/setup.sh (create workspace dirs) 2. Upload bootstrap/db2/commands.sh 3. tmux new-session -d -s sf-build-db2 4. Export DB2_BUILD_BRANCH=v1216, DB2_BUILD_JOBS=16 5. Execute commands.sh inside tmux └── setbldtree ~/db2 && bld -j 16 6. Poll tmux every 30s for sentinel: ✓ SF_BUILD_SUCCESS → Worker state = READY ✗ SF_BUILD_FAILED → Worker state = FAILED (retry up to 2x) ✗ Timeout 4h → Worker state = FAILED SSH disconnect tolerance: tmux keeps build alive; Orchestrator reconnects and resumes polling.
